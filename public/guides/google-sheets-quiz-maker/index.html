1. Set up the question booklet columns

Create a Google Sheet and use the first row for column headers. Add one multiple-choice question per row. QuizForge reads the question text, four choices, the correct option, and metadata used to organize the practice session.

2. Check each row before you share it

Quality data produces a fairer practice test. Fill each option, make the answer one of A, B, C, or D, and remove rows that are not questions. Use consistent subtopic names so related questions stay together in your results.

A quick pre-import check

Keep the headers in the first row, ensure every question has four choices, and avoid blank question rows. If answer choices are shuffled during a test, QuizForge keeps the labels in the standard A–D order for a clear answer review.

3. Share a view-only Google Sheets link

In Google Sheets, select Share, set General access to Anyone with the link, and keep the access level as Viewer. Copy the normal Google Sheets URL. You do not need to publish the spreadsheet to the web.

Only include questions you are comfortable making available to anyone who has that Sheet link. QuizForge imports the selected data into the browser where you use it.

4. Import, personalize, and review

Open QuizForge and choose Import questions. Paste the Google Sheets link, check the preview, give the booklet a useful name, and optionally place it in a group. When you create a test, you can choose one booklet or the entire question bank, set a question count and time limit, select subtopics and difficulty, and decide whether to shuffle questions or answer options.

After submission, review the correct answers, explore marks and accuracy by subtopic and difficulty, then download a detailed PDF report. For individual questions, the answer review can open a targeted Google search for a fuller explanation.

Frequently asked questions

Why can’t QuizForge read my Google Sheet?

Confirm that the Sheet is accessible to anyone with the link as a Viewer, the URL is a normal Google Sheets link, and the selected tab contains the supported header row.

Can I combine several booklets?

Yes. Save separate Sheets or tabs as individual question booklets, organize them into groups, then choose Whole question bank when configuring a test.

Does QuizForge store my questions on its server?

No account is required. QuizForge stores imported booklets and test history in the browser on the device you use, so export a backup before clearing browser data or changing devices.
